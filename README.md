# KAID STORE · Documentación Oficial

Sistema de documentación técnica oficial para los scripts de **KAID STORE** (FiveM: ESX, QBCore, QBox).

## 🚀 Despliegue en GitHub Pages (Gratis)
1. Sube este repositorio a tu cuenta de GitHub con el nombre kaid-docs (o el que gustes).
2. Ve a la pestaña **Settings** > **Pages**.
3. En **Branch**, selecciona main (o master) y la carpeta / (root).
4. Guarda los cambios. Tu documentación estará online al instante bajo tu enlace de GitHub:
   https://tu-usuario.github.io/kaid-docs/
