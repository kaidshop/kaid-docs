kaid-illegalsog

Sistema completo e inmersivo de amarre, soga y colgamiento para FiveM. Permite maniatar opositores o colgarse en estructuras elevadas con soporte automático para múltiples frameworks e inventarios.

Comprar en Tebex

1. Requisitos

Antes de arrancar o utilizar este recurso, verifica que tu servidor cuente con las siguientes dependencias activas:

  • ox_lib: Debe estar instalado y asegurado antes de este recurso.
  • Framework compatible: QBX (qbx_core), QB-Core (qb-core) o ESX (es_extended).
  • Inventario compatible: ox_inventory, qb-inventory o inventario legacy de ESX.

2 & 3. Instalación

  • Copia la carpeta kaid-illegalsog en el directorio resources de tu servidor FiveM.
  • Añade el ensure a tu server.cfg asegurándote de colocar ox_lib primero:
server.cfg 
ensure ox_lib
ensure kaid-illegalsog

4. Añadir el item "rope" al Inventario

rope.png
Copia esta imagen en la carpeta images/ o html/images/ de tu inventario.
ox_inventory/data/items.lua 
['rope'] = {
    label = 'Rope',
    weight = 250,
    stack = true,
    close = true,
    description = 'A sturdy rope, useful for tying someone up.',
    client = {
        image = 'rope.png',
    },
},
qb-core/shared/items.lua 
['rope'] = {
    ['name'] = 'rope',
    ['label'] = 'Rope',
    ['weight'] = 250,
    ['type'] = 'item',
    ['image'] = 'rope.png',
    ['unique'] = false,
    ['useable'] = false,
    ['shouldClose'] = true,
    ['combinable'] = nil,
    ['description'] = 'A sturdy rope, useful for tying someone up.',
},
ESX Database SQL 
INSERT INTO `items` (`name`, `label`, `weight`, `rare`, `can_remove`)
VALUES ('rope', 'Rope', 250, 0, 1);

5. Configuración (config.lua)

Variable Opciones / Descripción
Config.Framework 'auto', 'qbx', 'qb' o 'esx'
Config.Inventory 'auto', 'ox_inventory', 'qb-inventory' o 'esx_inventory'
Config.Locale 'en' (default) o 'es'
Config.Commands Nombres de comandos (tie, release, hangSelf)
Config.RopeItem Item requerido (por defecto 'rope')
Config.RequireRopeItem true / false
Config.RemoveRopeOnUse true / false

7. Comandos por Defecto

Comando Efecto / Acción
/amarrar Amarra al jugador más cercano y lo cuelga de un techo o viga elevada.
/soltar Libera o cancela el colgamiento actual del jugador que está atado.
/colgarse Acción para colgarse uno mismo de la superficie o techo superior.

🛡️ Kaidzona

Sistema profesional y completo de Safe Zones poligonales para FiveM. Crea y gestiona zonas seguras 100% personalizables en tiempo real sin reiniciar el servidor.

Ver Video Demostración Discord Soporte

Mira el funcionamiento en tiempo real, la creación de puntos en el mapa y la interfaz intuitiva:

👉 Ver demostración completa en YouTube (https://www.youtube.com/watch?v=VZQ8m6GGJ5g)

🛡️ ¿Qué incluye Kaidzona?

🗺️ Creación de Zonas
  • • Zonas poligonales libres con N puntos en el mapa.
  • • Sin límite de zonas independientes.
  • • Guardado automático en base de datos MySQL.
🛡️ Protección Anti-VDM
  • • Invencibilidad total dentro del área.
  • • Desactiva colisión con vehículos (radio 40m).
  • • Wanted level eliminado automáticamente.
🔫 Bloqueo de Combate
  • • Bloqueo de disparos, apuntar y combate cuerpo a cuerpo.
  • • Desarmado automático de armas en mano.
  • • Bloqueo de más de 12 controles de combate.
🚗 Límite de Velocidad & UI
  • • Límite en km/h configurable por zona (0 = ilimitado).
  • • TextUI moderno personalizable (color HEX + 24 iconos).
  • • Panel de administración in-game con ox_lib.

⚙️ Requisitos Previos

  • ox_lib — Menús de contexto, notificaciones y TextUI.
  • oxmysql — Conexión y persistencia en base de datos.
  • qb-core — Framework base del servidor.
  • FiveM Build 3095+

🗃️ Base de Datos SQL

Ejecuta esta única tabla en tu base de datos MySQL / MariaDB:

kaidzona_table.sql 
CREATE TABLE IF NOT EXISTS `kaidzona_zones` (
  `id` INT NOT NULL AUTO_INCREMENT,
  `label` VARCHAR(100) NOT NULL DEFAULT 'SafeZone',
  `points` LONGTEXT NOT NULL,
  `settings` LONGTEXT NOT NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

🚀 Pasos de Instalación

  • Copia la carpeta Kaidzona dentro de la carpeta resources de tu servidor.
  • Ejecuta el script SQL en tu base de datos.
  • Agrega ensure Kaidzona en tu server.cfg después de ox_lib y oxmysql.
  • Configura tu licencia en config/config.lua y usa el comando /kaidzona en el servidor.

🔐 Permisos y Comandos

Comando Permisos / Detalle
/kaidzona Abre el menú de administración y creación de zonas. Requiere grupo admin o licencia configurada en el config.lua.
