kaid-illegalsog

Sistema completo e inmersivo de amarre y soga para FiveM. Permite maniatar opositores o colgarse en estructuras elevadas con soporte automático para múltiples frameworks e inventarios.

1. Requisitos Previos

Antes de arrancar o utilizar este recurso en tu servidor de FiveM, asegúrate de tener instaladas y activadas las siguientes dependencias:

  • ox_lib: Debe estar instalado e iniciado antes de este script.
  • Frameworks compatibles: QBX (qbx_core), QB-Core (qb-core) o ESX (es_extended).
  • Inventarios compatibles: ox_inventory, qb-inventory o ESX legacy inventory.

2 & 3. Instalación en el Servidor

Paso 1: Copia la carpeta kaid-illegalsog dentro del directorio resources de tu servidor.

Paso 2: En tu archivo server.cfg, asegúrate de asegurar ox_lib antes que este recurso:

server.cfg 
ensure ox_lib
ensure kaid-illegalsog

4. Añadir el item "rope" a tu Inventario

Copia el bloque correspondiente a tu inventario dentro de su respectivo archivo de definición de items:

  • ox_inventory: ox_inventory/data/items.lua
  • qb-inventory / qb-core: qb-core/shared/items.lua o qb-inventory/data/items.lua
  • ESX legacy: Ejecutar la consulta SQL en la tabla items.

Y copia la imagen rope.png a la carpeta de imágenes de tu inventario:

  • ox_inventory: ox_inventory/web/images/rope.png
  • qb-inventory: qb-inventory/html/images/rope.png
  • ESX legacy: inventory_images/images/rope.png (o la carpeta de tu recurso de imágenes)
Item: rope.png
Icono transparente de alta calidad incluido en el script.

Configuración para OX_INVENTORY:

ox_inventory/data/items.lua 
['rope'] = {
    label = 'Rope',
    weight = 250,
    stack = true,
    close = true,
    description = 'A sturdy rope, useful for tying someone up.',
    client = {
        image = 'rope.png',
    },
},

Configuración para QB-INVENTORY:

qb-core/shared/items.lua 
['rope'] = {
    ['name'] = 'rope',
    ['label'] = 'Rope',
    ['weight'] = 250,
    ['type'] = 'item',
    ['image'] = 'rope.png',
    ['unique'] = false,
    ['useable'] = false,
    ['shouldClose'] = true,
    ['combinable'] = nil,
    ['description'] = 'A sturdy rope, useful for tying someone up.',
},

Consulta SQL para ESX LEGACY:

SQL Database 
INSERT INTO `items` (`name`, `label`, `weight`, `rare`, `can_remove`)
VALUES ('rope', 'Rope', 250, 0, 1);

5. Configuración (config.lua)

Abre el archivo config.lua en la raíz del recurso para ajustar las propiedades deseadas:

Ajuste Descripción y Valores Disponibles
Config.Framework 'auto', 'qbx', 'qb' o 'esx'
Config.Inventory 'auto', 'ox_inventory', 'qb-inventory' o 'esx_inventory'
Config.Locale 'en' (English, por defecto) o 'es' (Español)
Config.Commands Nombres de los comandos (tie, release, hangSelf)
Config.RopeItem Nombre del item requerido para amarrar (por defecto 'rope')
Config.RequireRopeItem true / false — Exigir tener la cuerda en inventario para usar el comando
Config.RemoveRopeOnUse true / false — Consumir o gastar la cuerda al utilizarse

Nota: Mantener Config.Framework y Config.Inventory en 'auto' detecta automáticamente el framework y el inventario en casi el 100% de los servidores.

6. Reiniciar el Recurso

En la consola de tu servidor o mediante RCON ejecuta:

Server Console 
restart kaid-illegalsog

Verás una línea de confirmación en la consola del servidor indicando el framework y el inventario detectados con éxito.

7. Comandos por Defecto

Comando Acción / Efecto
/amarrar Amarra al jugador más cercano y lo cuelga de un techo, viga o estructura elevada.
/soltar Libera o cancela el colgamiento actual del jugador amarrado.
/colgarse Acción de colgarse uno mismo del techo o estructura superior.

Los 3 comandos pueden renombrarse a tu gusto en config.lua bajo Config.Commands.
